# Tanıtım görselleri

Bu klasördeki görseller, proje geliştirilirken alınan gerçek ekran görüntüleri ve oyun kaydından hazırlanmıştır.

| Dosya | Kaynak ve kullanım |
|---|---|
| `grove-run-gameplay.gif` | 5 Ekim 2026 tarihli `20261005-2128-02.4377673.mp4` kaydının oyun içi bölümü; Unity arayüzü kırpılmıştır. |
| `gameplay-landscape.jpg` | Aynı kayıttan alınan yatay oyun içi kare. |
| `gameplay-portrait.jpg` | Geliştirme sırasında paylaşılan dikey oyun önizlemesi. Görselde önceki parkur süresi görünür. |
